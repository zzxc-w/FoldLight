# Remaining device verification

Automated verification was performed in desktop Chrome on Windows with Chromium touch emulation. Actual iPad Safari, Apple Pencil, installation UI, Web Share/download behavior, and sustained hardware frame rates have not been tested.

Use the production `dist/` build over HTTPS on the iPad (localhost is only local to the device on which the server runs).

1. In Safari, open each fold and each supplementary model. Confirm that every fabric surface is visible, including Pipe, Zigzag, Spiral, Diaper, Tension, Sleeve, Skirt, and Shoulder scarf; a shadow without its surface is a failure. Check Clay, Cel, Anime, and Normals in full and reduced quality. Orbit from front to back; confirm that the fabric has volume and spiral/sleeve/skirt have no open wrap seam. Check extreme fold controls.
2. In Orbit mode, use one finger and Apple Pencil to rotate. Switch to Move and drag normally to pan the reference in the screen plane. Test the directional pan buttons, zoom buttons, two-finger gestures, and right-drag with a mouse. Confirm that no page scrolling occurs in the viewport. Drag each slider and scroll the inspector independently.
3. Drag the gold light with touch and Pencil, then adjust azimuth/elevation numerically via the sliders. Confirm that shadows follow the light. Compare Studio, Dramatic, and Rim.
4. Switch Clay, Cel (2 through 5 bands), Anime, and Normals. Adjust Anime highlight/rim strength while moving the light, and inspect the head, hand, hair, and cloth. Compare threshold adjustment against shadow softness. Turn values view, outline, and light-facing visualization on/off.
5. Rotate between portrait and landscape. Toggle the settings panel, inspect the bottom sheet, and confirm that the model can be framed, all controls can be reached, and Safari bars/notches/home indicator do not obscure controls.
6. Switch perspective/orthographic and each camera preset; confirm that switching retains apparent scale. Reset immediately after a fast orbit/pan, then check that the reference remains still. The F key is optional with a hardware keyboard.
7. Export both regular and transparent PNGs. Verify Safari's download/save flow, correct dimensions, no interface or gizmo, and a useful image in Photos or Files. Import the transparent version into a drawing app and confirm that the background is transparent and the model opaque. On constrained devices, try Reduced quality if a full export fails.
8. Save a named lighting preset, close/reopen the app, then load and delete it. Confirm that reset all preserves the library. Check that storage-unavailable errors are explained if private browsing/storage restrictions apply.
9. Wait for the Help dialog's offline-ready message. Use Share → Add to Home Screen. Open the installed app online, close it, enable airplane mode, and reopen. Change models and shading; load a preset; export an image. Return online before testing updates.
10. Leave the app in the background and return; confirm rendering resumes. Study a high-detail mesh while moving the light for several minutes and watch for heat, stutter, or context loss. Compare Reduced quality. Record actual FPS using Safari's developer tools if available; this build does not claim a measured 30–60 FPS on iPad.
11. Serve a newer build, open it online, close all app tabs/windows, and reopen. Confirm the new build activates and saved presets survive.
12. Test Light, Dark, and Follow device themes. In Follow device, switch iPad appearance while FoldLight remains open; confirm interface and viewport adapt. Reload/relaunch and confirm the selected preference survives. In explicit Light/Dark, changing the device appearance must not override the selection.
13. Select a model and Anime rendering, adjust study controls, then reload/relaunch. Confirm the study resumes while the camera starts in a useful default view. Check that a malformed/unavailable storage entry falls back to usable settings.
14. Import local GLB, glTF with its `.bin` companion selected at the same time, OBJ, and ASCII/binary STL files through Safari's file picker. Confirm that each model is centered, grounded, and usable in every shading mode. Original materials and textures are intentionally replaced by study materials. If a model's up direction is different, correct it with model rotation controls and use Fit.
15. Use the Edit model strip to Move, Rotate, and Scale with finger and Pencil, rapidly switching tools between gestures. Confirm the camera stays still while editing the model; select View or the camera Orbit/Move buttons to return to camera gestures. Use Transform to enter exact position/rotation/scale values and try the ±90° shortcuts on a Z-up model. Test 0.1× and 5× scale, Fit, Place on ground, and all transform resets. Switch to a built-in reference and back: each model's transform should be retained for the session. Check silhouette/wireframe and PNG exports after transforming. **Remove imported model** should return to a usable built-in reference.
16. Try a malformed file, missing glTF buffer, remote buffer URL, compressed model, and a model over the stated import limits. Confirm that each shows a useful message while the previously loaded model remains usable. Repeat imports and removals to watch for increasing memory use or instability.
17. Export a PNG of an imported model with regular and transparent backgrounds; verify the result in a drawing app. Reload the app and confirm that it starts with a built-in reference and explains that local files need to be selected again. Repeat import while offline after the production app has been cached.

Known scope limits: stylized parametric folds rather than cloth physics; a simplified head rather than anatomical reference; view-space normals; light-facing diagnosis without occlusion; fixed secondary-light direction; approximate inflated-mesh contours; no comparison pane. Imports use geometry and the default pose, without source textures/materials or animation playback. Very deep/dense folds can intersect or show faceting, and shadow maps may show discretization at grazing angles. Shadow softness is a filter radius, not an area-light simulation.
